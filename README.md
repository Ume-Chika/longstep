# Longstep

長期目標を、現在地・中間目標・次の行動に分解して可視化する目標管理サイトです。

公開URL：<https://ume-chika.github.io/longstep/>

## 開発方針

- GitHub Pagesで公開できる静的サイトとして開発する
- 目標の立案・更新はユーザーが普段使うLLMに任せる
- サイトはプロンプト生成、計画の保存、可視化、JSON入出力を担当する
- 計画データはIndexedDBを中心にブラウザ内へ保存する
- JSONをバックアップとLLMとの受け渡しに使う

## ステータス

現在はMVPの開発・公開準備段階です。

`prototypes/`には検討用のモックを置きます。このディレクトリはGit管理対象外です。
